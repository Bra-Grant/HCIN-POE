Frequently Asked Questions

How does the Peer Verification workflow function?

Every uploaded module overview is verified by 3 independent student peers using a quality scoring rubric before it receives a verification badge.

Are academic referencing expectations maintained?

Yes. All summary sheets must adhere to current IIE Harvard Anglia style guide expectations, including correct in-text citations and complete reference lists.
